# Exercise 1 (example)

A **sorting algorithm** is an algorithm that takes a *list of numbers* and returns a *sorted list* where numbers are ordered in (typically) increasing order. If there are duplicates, we typically say the list is sorted in "non-decreasing" order.

The simplest sorting algorithm is **bubble sort**, which works by repeatedly swapping adjacent elements that are out of order. However, this is **not an efficient algorithm** as it has *quadratic* running-time of $O(n^2)$ where $n$ is the number of elements.
