# Sorting Algorithms

## Exercise 2 (task)

We can improve the efficiency of the **bubble sort algorithm** by doing two optimisations:
1. stopping early if no swaps are made
2. reducing the bound of the inner loop on each iteration

**Optimisation 1** works because if no swaps are made, the *list is already sorted* so we can break the outer loop. **Optimisation 2** works because each pass of bubble sort moves the largest element to the end, so the sorted list builds from the top down. This means on pass $i \ge 0$, the last $i$ elements of the list are sorted. 

**Task**: Complete the code to implement these two optimisations.

**Note**. This *does not* improve the Big-O running time complexity, it is still $O(n^2)$, but this version is typically faster as it does less work.
