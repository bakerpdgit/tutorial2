# Sorting Algorithms

## Exercise 4 (task)

The implementation of merge sort shown earlier returns a new sorted array instead of modifying the original one. Sometimes, we prefer to sort the array **in-place** so we do not return a new array because we can use less memory. We can do this by providing *indexes* for the upper and lower bounds of the subarray instead.

**Task**: Complete the code to merge sort an array in-place.

**Note**. This is not *technically* fully in-place because we use a temporary array in the `merge` subroutine. A $O(1)$ space implementation is more complicated and is not shown here. This implementation still has a space complexity of $O(n)$.
